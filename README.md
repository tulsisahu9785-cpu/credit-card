# 💳 Credit Card Fraud Detection Dashboard

## 📌 Project Overview

The Credit Card Fraud Detection Dashboard is an interactive Excel-based business intelligence project designed to analyze credit card transaction data and identify fraud patterns. The dashboard provides actionable insights through dynamic visualizations, helping users monitor fraudulent activities across multiple dimensions such as time, transaction type, merchant, country, and customer demographics.

---

## 🎯 Objective

- Analyze credit card transaction data to detect fraud trends.
- Identify high-risk merchants, countries, and transaction types.
- Provide interactive business insights using Excel dashboards.
- Support data-driven decision-making through visual analytics.
